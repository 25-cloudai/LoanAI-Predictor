LoanAI is an end-to-end Machine Learning project that predicts whether a customer is likely to repay a loan based on demographic, financial, and credit-related information. The application leverages a Random Forest Classifier trained on loan repayment data and provides real-time risk assessment through an interactive Streamlit web application
